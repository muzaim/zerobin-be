# Ownership Authorization

Implement ownership-based authorization.

Requirements:

Users must only be able to access their own resources unless explicitly granted permissions.

Examples:

User A cannot:

- View User B profile
- Update User B profile
- Delete User B profile
- Access User B resources

User B cannot access User A resources.

Implement reusable ownership middleware and authorization layer.

Provide reusable helpers:

- IsOwner()
- AuthorizeOwnership()

Ownership validation must be reusable across all future modules.

Future modules:

- Foods
- Blogs

Each module should be able to define:

OwnerID

and automatically enforce ownership checks.

Unauthorized access should return:

403 Forbidden

using standardized API responses.
